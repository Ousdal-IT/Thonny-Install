# Skjermbilder

Skjermbilder i denne katalogen skal være **verifiserte** og knyttet til et konkret steg i guiden.

## Regler

1. Bruk PNG eller WebP.
2. Ikke legg inn personopplysninger, brukernavn, e-postadresser eller andre private data.
3. Beskjær til området brukeren faktisk trenger å se.
4. Marker klikkpunkt med nummer/pil uten å skjule knappeteksten.
5. Registrer bildet i `manifest.json` før det tas i bruk.
6. Oppgi OS, OS-versjon, Thonny-versjon, språk, kilde og dato.
7. Et bilde som ikke lenger samsvarer med aktuell UI skal merkes `stale` eller erstattes.
8. Guiden må fortsatt være forståelig uten bilder.

## Filnavn

`<os>-<steg>-<kort-beskrivelse>.<ext>`

Eksempler:

- `windows-download-thonny.webp`
- `windows-installer-start.webp`
- `macos-download-choice.webp`
- `thonny-first-run.webp`

Skjermbilder er dokumentasjon, ikke dekorasjon.
