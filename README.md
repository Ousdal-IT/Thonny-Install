# Thonny Install

En enkel, utskriftsvennlig steg-for-steg-guide fra **Ousdal IT** for å installere Thonny og komme i gang med Python.

## M0

M0 inneholder:

- norsk HTML-guide
- enkel og lesbar utforming
- utskriftsvennlig CSS for A4/PDF
- Windows-, macOS- og Linux-spor
- første Python-program
- kort feilsøkingsdel
- GitHub Pages-workflow

## Lokal visning

Åpne `index.html` direkte i nettleseren.

## PDF

Siden er laget for utskrift. Velg **Skriv ut** i nettleseren og deretter **Lagre som PDF**.

Senere milepæler kan legge til automatisert PDF-bygg, skjermbilder, engelsk språkversjon og mer detaljert plattformspesifikk hjelp.
