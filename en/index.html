Install Python and Thonny – step by step

No previous experience needed. Do one thing at a time. Do not skip steps.

Windows or Mac? Install Thonny first. Python is normally included with Thonny, so you usually do not need to install Python separately.
WindowsMacLinuxNorsk

First: open the Thonny website

  1. Turn on the computer and wait for the desktop.
  2. Make sure you are connected to the Internet.
  3. Open your web browser, for example Edge, Chrome, Firefox or Safari.
  4. Click once in the address bar at the top.
  5. Type thonny.org.
  6. Press Enter.
  7. Check that the address is https://thonny.org/.
You should now see: the Thonny website with download choices for Windows, macOS and Linux.

Windows 10 or 11

A. Download

  1. Find Official downloads for Windows on thonny.org.
  2. Most ordinary PCs use Intel or AMD. Choose Intel or AMD computers.
  3. Choose ARM64 only if you know the PC uses Windows on ARM/Snapdragon.
  4. If asked, choose Save or Download.
  5. Wait for the download to finish.
✓ Check: You should now have a downloaded Thonny installer.

B. Install

  1. Open the browser's Downloads list. In Edge, Chrome and Firefox, Ctrl + J usually opens it.
  2. Find and open the Thonny file.
  3. If Windows shows a security prompt, check that this is the file you downloaded from thonny.org.
  4. Keep the standard choices unless you have a reason to change them.
  5. Continue through the installer and wait until it finishes.

C. Start

  1. Open Start.
  2. Type Thonny.
  3. Open Thonny from the search results.
You should now see: Thonny with an editor at the top and a Shell area below.

macOS

A. Identify your Mac

  1. Open the Apple menu .
  2. Choose About This Mac.
  3. If it shows an Apple M-series chip, choose Apple Silicon on thonny.org.
  4. If it shows Intel, choose Intel Macs.

B. Download and install

  1. Find Official downloads for macOS.
  2. Choose the version for your Mac.
  3. Wait for the .pkg file to download.
  4. Open Downloads and double-click it.
  5. Follow the installer. Approve with your password or Touch ID if macOS asks.
  6. Open Applications and start Thonny.
✓ Check: The Thonny window should be open.

Linux

On Linux, Thonny normally uses Python 3 already installed on the system.

  1. Open a Terminal.
  2. Copy the whole line below:
wget -qO- https://thonny.org/installer-for-linux | bash
  1. Paste it into the terminal.
  2. Press Enter.
  3. Read and follow the questions shown.
  4. Wait for installation to finish.
  5. Find Thonny in the application menu and start it.
✓ Check: The Thonny window should be open.

Test that everything works

  1. Click the large editor area at the top of Thonny.
  2. Type exactly:
print("Hello!")
  1. Press F5, or click the green Run button.
  2. If asked to save, choose Documents and name the file hello.py.
  3. Look in the Shell area below.
You should see:
Hello!
If you see “Hello!”, you are done. Thonny and Python work.

I'm stuck

Choose the sentence that best matches what you see. You do not need to understand an error message first.

“I can't find the downloaded file”

Open your browser's Downloads list and look for a file with thonny in its name.

“Thonny is installed, but I can't find it”

Restart the computer, then search for Thonny in Start, Applications, or your Linux application menu.

“F5 does not show Hello!”

Compare print("Hello!") character by character with the example above. Make sure you typed it in the editor, not directly in Shell.

Security stop: Do not disable security features just to get past an installation warning. If you are unsure, stop and verify that the installer came from thonny.org.
