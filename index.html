Installer Python og Thonny – steg for steg

Ingen forkunnskaper nødvendig. Følg ett punkt om gangen.

Den enkleste løsningen: På Windows og macOS kommer Thonny med Python inkludert. Du trenger derfor vanligvis ikke installere Python separat.

Windows macOS Linux

Før du begynner

  1. Slå på datamaskinen.
  2. Koble datamaskinen til Internett.
  3. Åpne nettleseren du vanligvis bruker, for eksempel Edge, Chrome, Firefox eller Safari.
  4. Gå til thonny.org.

Denne guiden tar utgangspunkt i Thonny 5.0.0, som er den stabile versjonen på thonny.org ved M0.

Windows 10 eller 11

1. Last ned Thonny

  1. På thonny.org finner du området Official downloads for Windows.
  2. Har du en vanlig PC med Intel- eller AMD-prosessor, velg installasjonsfilen for Intel or AMD computers.
  3. Har du en Windows-PC med ARM-prosessor, for eksempel enkelte Snapdragon-maskiner, velg ARM64-versjonen.
  4. Vent til filen er ferdig lastet ned.

2. Start installasjonen

  1. Åpne listen over nedlastede filer i nettleseren.
  2. Klikk på Thonny-filen du nettopp lastet ned.
  3. Hvis Windows spør om du vil tillate at programmet gjør endringer, kontroller at filen er Thonny-installasjonen du lastet ned fra thonny.org, og fortsett.
  4. Følg veiviseren på skjermen. Standardvalgene passer for de fleste.
  5. Når installasjonen er ferdig, lukk installasjonsprogrammet.

3. Start Thonny

  1. Klikk på Start-knappen i Windows.
  2. Skriv Thonny.
  3. Klikk på Thonny i søkeresultatet.

macOS

1. Finn riktig Mac-versjon

  1. På thonny.org finner du området Official downloads for macOS.
  2. Har du en nyere Mac med Apple Silicon, som M1, M2, M3 eller nyere, velg Apple Silicon.
  3. Har du en eldre Intel-Mac, velg Intel Macs.
  4. Vent til .pkg-filen er ferdig lastet ned.

2. Installer

  1. Åpne den nedlastede .pkg-filen.
  2. Følg installasjonsveiviseren.
  3. Hvis macOS spør etter passordet ditt eller Touch ID, godkjenn installasjonen.
  4. Når installasjonen er ferdig, åpne Programmer og start Thonny.

Linux

Linux-versjonen av Thonny bruker vanligvis Python 3 som allerede finnes i systemet.

Enkel metode

  1. Åpne et terminalvindu.
  2. Skriv inn kommandoen under nøyaktig slik den står.
wget -qO- https://thonny.org/installer-for-linux | bash
  1. Trykk Enter.
  2. Følg beskjedene i terminalen.
  3. Start Thonny fra programmenyen når installasjonen er ferdig.

På enkelte distribusjoner kan Thonny også installeres via Flatpak, Snap, APT eller DNF. Disse pakkene kan være eldre enn den offisielle versjonen.

Test at Python virker

  1. Start Thonny.
  2. Klikk i det store hvite redigeringsfeltet øverst.
  3. Skriv nøyaktig dette:
print("Hei!")
  1. Klikk på den grønne Run-knappen, eller trykk F5.
  2. Hvis Thonny spør hvor filen skal lagres, velg et sted du finner igjen, for eksempel Dokumenter, og kall filen hei.py.
  3. Se nederst i Thonny-vinduet.
Ser du ordet «Hei!»?
Da virker både Thonny og Python. Du har kjørt ditt første Python-program.

Hvis noe ikke virker

  • Thonny starter ikke: Start datamaskinen på nytt og prøv igjen.
  • Du finner ikke nedlastingen: Trykk Ctrl + J i de fleste Windows/Linux-nettlesere, eller åpne Nedlastinger i Safari.
  • Du er usikker på hvilken versjon du skal velge: Gå tilbake til thonny.org og bruk teksten ved siden av hver nedlasting som veiledning.
  • Linux-kommandoen feiler: Kontroller at datamaskinen er koblet til Internett og at wget finnes.
