Installer Python og Thonny – steg for steg

Ingen forkunnskaper nødvendig. Gjør én ting om gangen. Ikke hopp over punkter.

Windows eller Mac? Installer Thonny først. Python følger med Thonny, så du trenger normalt ikke installere Python separat.
Jeg har WindowsJeg har MacJeg har LinuxEnglish

Først: åpne Thonny-nettsiden

  1. Slå på datamaskinen og vent til skrivebordet vises.
  2. Kontroller at du er koblet til Internett.
  3. Åpne nettleseren. Det kan for eksempel være Edge, Chrome, Firefox eller Safari.
  4. Klikk én gang i adressefeltet helt øverst i nettleseren.
  5. Skriv thonny.org.
  6. Trykk Enter.
  7. Kontroller at adressen i nettleseren er https://thonny.org/.
Dette skal du se nå: En nettside med navnet Thonny og egne nedlastingsvalg for Windows, macOS og Linux.
✓ Kontroll: Du skal nå se nettsiden til Thonny.

Windows 10 eller 11

A. Last ned

  1. Finn overskriften Official downloads for Windows på thonny.org.
  2. De fleste vanlige PC-er bruker Intel eller AMD. Klikk Windows-installasjonen for Intel or AMD computers.
  3. Bare hvis du vet at PC-en bruker Windows on ARM/Snapdragon, velger du ARM64.
  4. Hvis nettleseren spør om du vil laste ned filen, velg Lagre eller Download.
  5. Vent til nedlastingen er ferdig. Ikke lukk nettleseren ennå.
Dette skal du se nå: Nettleseren viser at en Thonny-installasjonsfil er ferdig lastet ned.
✓ Kontroll: Du skal ha en nedlastet Thonny-installasjonsfil.

B. Installer

  1. Åpne nettleserens liste over nedlastinger. I Edge, Chrome og Firefox kan du vanligvis trykke Ctrl + J.
  2. Finn Thonny-filen du nettopp lastet ned og klikk på den.
  3. Hvis Windows viser et sikkerhetsspørsmål, kontroller at dette er Thonny-filen fra thonny.org før du fortsetter.
  4. Når installasjonsvinduet åpnes, les hvert vindu og behold standardvalgene dersom du ikke har en grunn til å endre dem.
  5. Klikk deg videre gjennom installasjonen og vent til den melder at den er ferdig.
  6. Lukk installasjonsprogrammet.

C. Start

  1. Klikk Start-knappen på oppgavelinjen.
  2. Skriv Thonny.
  3. Klikk Thonny i søkeresultatet.
Dette skal du se nå: Thonny har et redigeringsfelt øverst og et Shell-område nederst.
✓ Kontroll: Et vindu med Thonny skal åpne seg. Gå videre til «Test at alt virker».

macOS

A. Finn hvilken Mac du har

  1. Klikk Apple-menyen  øverst til venstre.
  2. Velg Om denne maskinen / About This Mac.
  3. Ser du Apple M1, M2, M3, M4 eller nyere Apple-brikke, velger du Apple Silicon på thonny.org.
  4. Ser du Intel, velger du Intel Macs.

B. Last ned og installer

  1. På thonny.org, finn Official downloads for macOS.
  2. Klikk versjonen som passer maskinen din.
  3. Vent til .pkg-filen er lastet ned.
  4. Åpne Nedlastinger / Downloads og dobbeltklikk filen.
  5. Følg installasjonsvinduene. Godkjenn med passord eller Touch ID hvis macOS ber om det.
  6. Når installasjonen er ferdig, åpne Programmer / Applications og dobbeltklikk Thonny.
Dette skal du se nå: Thonny har et redigeringsfelt øverst og et Shell-område nederst.
✓ Kontroll: Thonny-vinduet skal være åpent.

Linux

På Linux bruker Thonny normalt Python 3 som allerede er installert i systemet.

  1. Åpne Terminal.
  2. Kopier hele linjen under:
wget -qO- https://thonny.org/installer-for-linux | bash
  1. Klikk i terminalvinduet og lim inn kommandoen.
  2. Trykk Enter.
  3. Les og følg spørsmålene som vises i terminalen.
  4. Vent til installasjonen er ferdig.
  5. Åpne programmenyen, søk etter Thonny, og start programmet.
✓ Kontroll: Thonny-vinduet skal være åpent.

Linux-distribusjoner kan også tilby Thonny via egne pakkesystemer. Versjonen der kan avvike fra den offisielle.

Test at alt virker

Nå skal vi lage et bitte lite Python-program.

  1. Se etter det store redigeringsfeltet øverst i Thonny.
  2. Klikk én gang i feltet.
  3. Skriv nøyaktig:
print("Hei!")
  1. Trykk F5, eller klikk den grønne Run-knappen.
  2. Hvis du blir bedt om å lagre filen, velg Dokumenter og skriv filnavnet hei.py.
  3. Klikk Lagre.
  4. Se i Shell-området nederst i Thonny.
Du skal se:
Hei!
Ser du «Hei!»? Da er du ferdig. Thonny og Python virker, og du har kjørt ditt første Python-program.

Jeg sitter fast

Velg setningen som passer best. Du trenger ikke forstå feilmeldingen først.

«Jeg finner ikke filen jeg lastet ned»

  1. Ikke last ned på nytt ennå.
  2. Åpne nettleserens Nedlastinger / Downloads.
  3. På Windows og Linux kan Ctrl + J åpne nedlastingslisten i mange nettlesere.
  4. Se etter en fil med thonny i navnet.
✓ Fant du filen? Åpne den og fortsett installasjonen der du slapp.

Windows: «Ingenting skjer når jeg åpner filen»

  1. Vent 20 sekunder. Installasjonsvinduet kan bruke litt tid på å vises.
  2. Se på oppgavelinjen etter et nytt eller blinkende vindu.
  3. Hvis ingenting vises, åpne Nedlastinger og prøv filen én gang til.
  4. Hvis Windows viser en sikkerhetsmelding, les den før du velger noe. Fortsett bare når du har kontrollert at filen kom fra thonny.org.

Mac: «macOS vil ikke åpne installasjonen»

  1. Kontroller først at filen ble lastet ned fra thonny.org.
  2. Ikke slå av sikkerhetsfunksjoner for å få installasjonen til å virke.
  3. Les meldingen macOS viser. Hvis den sier at filen er skadet, ukjent eller blokkert, stopp og kontroller at du valgte riktig Mac-versjon.
Stoppunkt: Er du usikker på en sikkerhetsadvarsel, ikke klikk deg forbi den bare for å komme videre.

Linux: «Kommandoen virker ikke»

  1. Kontroller at du kopierte hele kommandoen.
  2. Kontroller Internett-forbindelsen.
  3. Hvis terminalen sier wget: command not found, mangler programmet wget.
  4. Bruk distribusjonens vanlige pakkebehandler til å installere wget, eller installer Thonny fra distribusjonens programbutikk/pakkesystem.

«Thonny er installert, men jeg finner det ikke»

  1. Lukk installasjonsprogrammet.
  2. Start datamaskinen på nytt.
  3. Windows: åpne Start og skriv Thonny.
  4. Mac: åpne Programmer / Applications og se etter Thonny.
  5. Linux: åpne programmenyen og søk etter Thonny.

«Jeg trykker F5, men får ikke Hei!»

  1. Kontroller at linjen er nøyaktig print("Hei!").
  2. Kontroller at begge anførselstegn og begge parenteser er med.
  3. Kontroller at du skrev i redigeringsfeltet, ikke direkte i Shell.
  4. Trykk F5 igjen.
  5. Se nederst i Shell.
Hvis du ser rød tekst: Ikke få panikk. Rød tekst er en feilmelding. Sammenlign først programlinjen tegn for tegn med eksemplet over.
